# DSH Plugins（DeepSeek Harness 动态插件）

两个 DeepSeek Harness 浏览器端动态插件：装饰型 UI 组件。

## 插件列表

| 插件 | 文件 | 功能 |
|---|---|---|
| 鲸鱼宠物 | `plugins/dk-whale-pet.js` | 座头鲸妈妈+宝宝，全界面慢速漫游、可拖拽、点击对话 |
| 对话导航 | `plugins/dk-chat-nav.js` | 右侧滚轮导航 + 向上翻一组按钮 + 顶部问题悬浮窗 |

## 环境要求

- DeepSeek Harness（DSH）——只有 Harness 才有 cordis 动态插件运行时
- 这两个是浏览器端（Client）插件，通过 cordis 工具加载

## 安装方法

1. 打开 Harness 对话，用 `cordis_define` 工具，把 `.js` 文件里 `return {...}` 函数体粘贴到 `code.client` 字段
2. `cordis_run` 激活
3. 界面弹"批准"时点击允许

## 插件说明

### dk-whale-pet（鲸鱼宠物）

- 座头鲸妈妈（180px）+ 宝宝（90px）
- 每 16 秒慢速漂移、13 秒游过去
- 妈妈可鼠标拖拽，宝宝同步跟随
- 点击对话：妈妈说"咕噜～/DK 在呢！/加油哦！/有事找我呀？"，宝宝说"咕噜咕噜～/妈妈妈妈！/我要游游！/嘿嘿～"
- 尾鳍/背鳍/胸鳍会摇动

### dk-chat-nav（对话导航）

- **右侧滚轮**：默认隐形，hover 浮现；每组对话一行（小线段 + 问话开头）；点击跳到该组对话开头；滚动吸附整行
- **向上翻按钮**：右下角"回到底部"按钮上方，点击向上翻一组对话
- **顶部问题悬浮窗**：往下滚动时显示当前（最后一组）对话的问题，滚回问题本身则消失；深浅主题自动适配

## 技术说明

- 两个插件共用 turnTail 锚点机制（对话每回合埋定位标记）
- 浏览器端可用全局：`ctx` / `React` / `host` / `styles` / `console`，定时器用 `ctx.get('timer')`
- 动态插件是进程内临时的，重启 Harness 后需重新加载
